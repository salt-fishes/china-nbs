# 数据口径说明

国家统计局同一主题下往往有多个指标，名称只差几个字，数值含义完全不同。`china-nbs` 的目标不是“猜一个”，而是**优先选常用口径，选不准就返回候选**。

## 1. 同比、环比、累计、当季

| 词 | 常见指标名 | 含义 |
|---|---|---|
| 同比 | `上年同月=100`、`上年同期=100`、`上年=100` | 与去年同期比 |
| 环比 | `上月=100`、`环比增长速度` | 与上一个周期比 |
| 累计 | `累计值`、`年初至今` | 从年初到当前周期 |
| 当季 | `当季值` | 单个季度，不是全年累计 |

默认规则：

- 问“GDP”且 `period=quarter`：默认取**累计值**（如 2026 前三季度累计）。
- 问“GDP当季”：取当季值；分省季度目前只有累计值，没有当季值。
- 问“CPI”且 `period=month`：默认取**上年同月=100**（同比）。
- 问“CPI累计”或“1–10月CPI”：需要明确累计口径时，建议用 `indicatorId` 选择，或把“累计”写进 query。

## 2. 现价、不变价

| 口径 | 含义 | 典型单位 |
|---|---|---|
| 现价 | 按当年价格计算 | 亿元 |
| 不变价 | 按基期价格计算，剔除价格因素 | 亿元 / 指数 |
| 指数 | 以上年为 100 或定基 | `上年=100`、`1978年=100` |

默认规则：

- 问“GDP 是多少/总量”：优先现价总量（亿元）。
- 问“GDP 增速/增长”：优先 `%`、`上年=100` 或“增长”指标，降权亿元总量。
- 问“GDP 指数”：优先 `上年=100`，降权 `1978年=100` / `1985年=100`（除非明确说“定基”）。
- 问“实际增速/不变价”：优先“不变价”。

## 3. 贡献率、拉动、构成、人均

这些词一旦被误选，答案会“看起来像 GDP，但完全不是 GDP 总量”。

默认规则：

- 未出现“贡献率/拉动/构成”时，对这些指标降权。
- 未出现“人均”时，对“人均国内生产总值”降权。
- 出现“贡献率”时，优先“贡献率”，并降权总量。
- 出现“人均”时，优先“人均”，并降权总量。

## 4. 单位与精度

- 库保留原始字符串 `rawValue`，同时给出 `value: number | null`。
- 展示时只加千分位，不改变小数位；例如 `1401879.2` → `1,401,879.2`。
- 单位来自 `show_name` / `du_name`，如 `亿元`、`%`、`万人`、`上年=100`。
- 缺失值 `""`、`—`、`--` 统一为 `null`，文本显示 `—`；序列末尾未发布的数据点会省略。

## 5. 修订与时间

- GDP 等数据存在初步核算、最终核实和修订；同一年的数值可能变化。
- 月度/季度数据一般在官方发布后数个工作日入库。
- 年度数据分统计公报、统计摘要、统计年鉴多批更新。
- 每个结果都带 `source.retrievedAt`（ISO 8601 UTC）；引用时请注明“查询时间”。

## 6. 分片

月度长序列常按统计制度周期拆分，例如居民消费价格分类指数（上年同月=100）：

```text
(2026-)
(2021-2025)
(2016-2020)
(-2015)
```

全国和分省的 CPI 分片 `cid` / `indicatorId` **不同**，但分组逻辑相同。`china-nbs` 会：

1. 按查询时间范围选择相交的分片；
2. 对每个分片单独请求；
3. 合并、按时间排序、去重；
4. 某个分片失败时返回其余分片，并在 `notes` 说明缺口。

除了内置的 CPI 分片，分类树解析还会做**通用分片发现**：如果选中的叶子名称带有 `(2021-)`、`(2016-2020)`、`(-2015)` 这类年份范围，会在同一父节点下查找同名兄弟叶子，按指标 `showName` 匹配后自动挂载为 `shards`。这样非 curated 的长序列也不会只返回当前分片。

注意：通过 `indicatorId` 精确选择候选时，解析器只拿到 `cid:indicId`，不会反查分类树，因此不会自动扩展分片；需要完整历史时请用关键词查询或自行指定范围。

## 7. 地区与 code

- `全国`：`000000000000`。
- 分省：`/getAllProvince` 返回 34 个地区（31 个省级行政区 + 台湾、香港、澳门）。
- `code` 是“范围 × 频率”矩阵：
  - 全国：月 `1`、季 `2`、年 `3`
  - 分省：月 `4`、季 `5`、年 `6`
  - 主要城市：年 `8`；月 `7` 是 36/70 城市汇总价格指数，不是单城市数据
  - 港澳台：月 `9`
- v0.2 已支持分省年度/季度/月度；分省季度目前只有 GDP 累计值和指数。
- 主要城市年度已支持 36 个主要城市（4 个直辖市按省级处理 + 32 个地级市；标准行政区划码 + `000000`，如广州 `440100000000`）；城市季度/月度单城市数据暂不支持。
- `compare` 对每个地区单独请求（实测 `das` 多地区只返回第一个）。

## 8. 交通邮电、金融、教育卫生与环境

- 交通邮电指标（旅客/货物运输量、旅客/货物周转量、快递量、快递业务收入、移动电话用户、宽带接入用户）均为**全国年度**口径。
- 年度金融指标（M2、金融机构各项存款、各项贷款）是**全国年度、年底余额**口径，不是月度增量。
- 月度金融指标在 `月度数据 > 金融 > 货币供应量` 下，提供 M2/M1/M0 的**期末值**和**同比增长**；它和年度表不是同一 `cid`，不要混用。
- 教育、卫生、环境 curated 均为**全国年度**口径；卫生总费用、供水、垃圾清运等数据通常滞后一年。
- 70 个大中城市住宅销售价格指数不在当前公开接口的分类树和搜索中，因此没有纳入 curated。
- 快递量单位是 `万件`，快递业务收入单位是 `万元`，不要与 `亿件` / `亿元` 混用。

## 9. 推荐用法

```ts
// 不确定口径时，先看候选
const r = await query({ action: 'search', query: 'GDP', period: 'year' });
if (r.error?.code === 'AMBIGUOUS') {
  console.log(r.candidates?.map((c) => c.displayName));
}

// 确定候选后，用 indicatorId 固定口径
await query({
  action: 'series',
  query: 'GDP',
  period: 'year',
  indicatorId: r.candidates?.[0]?.id,
  start: 2015,
  end: 2025,
});
```
