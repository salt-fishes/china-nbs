# 覆盖率与评测

`china-nbs` 的“覆盖率”分两层：

1. **范围覆盖**：全国、分省、主要城市；年度、季度、月度。
2. **指标覆盖**：常用指标走 curated 快速路径，长尾指标走搜索 + 分类树。

## 1. 当前范围

| 范围 | 年度 | 季度 | 月度 |
|---|---|---|---|
| 全国 | ✅ code=3 | ✅ code=2 | ✅ code=1 |
| 分省 | ✅ code=6 | ✅ code=5 | ✅ code=4 |
| 主要城市 | ✅ code=8（36 个） | — | —（code=7 是 36/70 城汇总） |
| 港澳台 | ⏳ | ⏳ | ⏳ |

分省覆盖 34 个地区（31 个省级行政区 + 台湾、香港、澳门）；但港澳台的数据集目前未验证出可用指标，暂不承诺。

主要城市内置 36 个（4 个直辖市按省级处理，32 个地级市），值使用标准行政区划码 + `000000`，例如广州 `440100000000`。上游只提供这 36 个主要城市，不能通过扩展列表增加城市数据。

覆盖矩阵：`npm run coverage:matrix` 按“常用指标 × 全国/分省/城市 × 年/季/月”输出目标缺口。当前 28 个目标 cell 缺口，主要集中在分省和城市。

## 3. 评测集

`scripts/eval-cases.ts` 维护 **198 条**用例：189 条 curated + 9 条非 curated fallback，覆盖：

- 全国/分省/主要城市
- 年度/季度/月度
- 总量/累计/同比/增速
- 别名与日期写法（`2025年10月`、`2025Q1`、`2025-10`）

每条用例包含：

```ts
{
  query: '2025年10月社零同比',
  period: 'month',
  scope: 'national',
  expectedKey: 'retail-growth-month-national',
  category: 'national-month',
}
```

`expectedKey` 指向 curated 条目；非 curated 用例也可以用 `expectedId` 固定 `cid:indicId`。

## 4. 运行

```bash
npm run eval        # 离线，只测 curated 快速路径，不请求上游
npm run eval:live   # 在线，curated + search/tree
```

当前结果：

```text
curated fast path: 159 cases
top-1: 189/189 (100.0%)
top-3: 189/189 (100.0%)

live resolver: 168 cases
top-1: 198/198 (100.0%)
top-3: 198/198 (100.0%)
fallback: 9/9
```

`eval:live` 会复用进程内缓存和 2 秒串行限流；不要把它放进 CI 的高频任务。

## 5. 覆盖率评估（0.3.0）

| 维度 | 现状 | 评价 |
|---|---|---|
| 地区范围 | 全国 + 34 分省 + 36 主要城市 | 高；港澳台无可用指标 |
| 频率 | 全国/分省 年/季/月；城市年 | 高；城市无季/月单城市数据 |
| 常用指标 | 160 个 curated，160 个唯一 `cid:indicId` | 中高；宏观主口径覆盖较好 |
| 长尾指标 | 搜索/分类树 fallback | 中低；本轮 fallback 9/9（小样本），此前 13 条难样本 9/13 |
| 时间序列 | 2 个 curated 分片指标 + 通用分片发现 | 中高；分类树叶子带年份范围时可自动合并 |
| 原始指标总量 | 官方约 7.6 万指标 | <0.2%；本项目不按原始指标宣称全覆盖 |
| 评测可信度 | curated 189/189；fallback 9/9（小样本） | 中；评测集是自建回归集，不是独立抽样 |
| 工程质量 | 63 个测试、lint/typecheck/build/smoke、负缓存/熔断/代理注入、MCP server | 高 |

综合判断：

- **常用宏观查询**（GDP/CPI/PPI/人口/社零/固投/收入/财政/粮食/进出口/工业/失业率/房地产/能源/交通邮电/金融/教育/卫生/环境）：覆盖较好，主观估计 **80–85%** 的常见问法可直接命中。
- **长尾指标**：依赖搜索/分类树；本轮 fallback 9/9，但样本已从 13 条缩到 9 条，且是修复后的样本。此前 13 条难样本为 9/13，因此长尾仍不能视为全覆盖。
- **原始指标总量**：160 / ~76,000，按编号计 **<0.2%**；不能对外宣称“所有统计指标全覆盖”。
- **范围覆盖**：全国和分省的年/季/月基本铺满；城市只覆盖官方 36 个；港澳台、部门、国际、普查仍未覆盖。

## 6. 已知缺口

- 港澳台、部门、国际、普查数据尚未验证；`code=9` 当前返回空指标。
- 主要城市只覆盖上游提供的 36 个；其他地级市没有城市年度数据。
- 分省月度社零数据集只到 2010-12，因此没有 curated。
- 分省年度固投、分省季度社零只有增速，没有总量。
- 卫生总费用、供水、垃圾清运等年度数据通常滞后一年，查询时不要假设当年值已发布。
- 70 个大中城市住宅销售价格指数不在当前公开接口的分类树和搜索中，未纳入 curated。
- 长尾指标的通用分类树解析仍受请求预算和叶子匹配限制；新增高频指标应优先补 curated + 评测用例。
